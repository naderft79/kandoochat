# ربات استخراج کیس از تلگرام

ربات پایتون برای استخراج عکس از کانال تلگرام و ساخت پروفایل فیک در دیتابیس کندو.

## نصب

```bash
cd d:\kandoo\telegram_bot
pip install -r requirements.txt
```

## اجرا

```bash
python bot.py
```

### اولین اجرا

در اولین اجرا، Teletron از شما شماره موبایل و کد تایید تلگرام را می خواهد. بعد از تایید، نشست در فایل `kandoo_session.session` ذخیره می شود و اجراهای بعدی نیازی به ورود ندارند.

## عملکرد ربات

۱. به کانال `@masaj_vip` متصل می شود
۲. همه پیام ها را بررسی می کند و کیس ها (گروه عکس ها) را شناسایی می کند
۳. عکس های هر کیس را دانلود می کند:
   - اگر ۴ عکس یا بیشتر: عکس اول = پروفایل، ۳ عکس بعدی = گالری
   - اگر کمتر از ۴: یک عکس رندوم = پروفایل، بقیه = گالری (حداکثر ۳)
۴. عکس ها را در `public/uploads/` کپی می کند
۵. برای هر کیس یک کاربر فیک با اطلاعات کامل (نام، سن، شهر، شغل، بیو) می سازد
۶. به صورت رندوم:
   - سکه (۶۰٪ احتمال دریافت)
   - تیک آبی (۶۰٪ احتمال)
   - وضعیت ویژه (۱۵٪ احتمال)

## تنظیمات

فایل `config.py` را برای تغییر تنظیمات ویرایش کنید:
- `API_ID` و `API_HASH`: کلید های تلگرام
- `CHANNEL`: نام کانال هدف
- `DB_PATH`: مسیر دیتابیس SQLite
- `UPLOADS_DIR`: پوشه ذخیره عکس ها
