# کندو (Kandoo) — سایت همسریابی

سایت همسریابی با سیستم مالی مبتنی بر سکه، چت با قفل اشتراک و پنل مدیریت کامل.

## تکنولوژی ها

- **Next.js 16** (App Router + Turbopack)
- **Prisma 7** + SQLite (آماده مهاجرت به PostgreSQL)
- **Tailwind CSS 4** + Framer Motion
- احراز هویت با **JWT (jose)** و کوکی httpOnly + رمزنگاری **bcrypt**

## اجرا

```bash
npm install
npx prisma migrate dev   # ساخت دیتابیس
npx prisma db seed       # مدیر + پروفایل های نمونه
npm run dev              # اجرا روی http://localhost:3000
```

## دسترسی مدیر

- شماره موبایل: `09120000000`
- رمز عبور: `Admin@Kandoo1404`
- پنل مدیریت: `/admin`

کاربران نمونه: شماره های `09121000001` تا `09121000010` با رمز `Sample@1234`

## قوانین کسب و کار

- هر کاربر فقط **جنس مخالف** در **شهر خودش** را می بیند
- ارسال پیام فقط وقتی مجاز است که **حداقل یک طرف** اشتراک فعال داشته باشد
- اشتراک ماهانه (پیش فرض ۳۹۸,۰۰۰ تومان) فقط با **سکه** خریداری می شود
- ارزش هر سکه توسط مدیر تعیین می شود (پیش فرض ۱۰,۰۰۰ تومان)
- برداشت سکه و تبدیل به تومان از **۵۰ سکه** به بالا با تایید مدیر

## نکات

- درگاه پرداخت فعلا شبیه سازی شده است؛ محل اتصال درگاه واقعی در `src/app/api/wallet/buy/route.ts` مشخص شده
- متغیرهای محیطی در `.env` (شامل `JWT_SECRET` و `DATABASE_URL`)
